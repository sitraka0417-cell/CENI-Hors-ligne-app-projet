CENI Hors-ligne — application Android (APK) compilée par GitHub Actions
========================================================================
Dossier web/  = l'application d'origine, INCHANGÉE (octet pour octet). Le workflow vérifie son SHA-256 (SHA256SUMS.txt),
                puis vérifie encore que les fichiers à l'intérieur de l'APK sont identiques.
Seule différence dans l'APK : index.html reçoit UNE ligne <script src="native-shim.js"> (pont d'export : la WebView Android
ne sait pas télécharger un fichier blob, donc « Exporter TOUT » passe par la feuille de partage Android).

UTILISATION
1. Créez un dépôt GitHub (de préférence PRIVÉ), envoyez TOUT le contenu de ce dossier (y compris .github/ et signing/).
2. Onglet « Actions » > « Build APK (CENI Hors-ligne) » > (se lance tout seul au push, ou « Run workflow »).
3. Quand c'est vert : ouvrez l'exécution > « Artifacts » > « CENI-Hors-ligne-apk » (zip contenant CENI-Hors-ligne.apk).
4. Copiez l'APK sur le téléphone et installez (autoriser « sources inconnues »).

IMPORTANT
- La clé de signature (signing/ceni-release.keystore) est FIXE : les futures versions se installent PAR-DESSUS l'ancienne
  sans perdre les données. Gardez ce fichier ; ne le changez jamais.
- Les données de la PWA (Chrome) ne passent pas automatiquement dans l'APK : sur l'ancienne version, faites ⬇ Exporter TOUT,
  puis dans l'APK ☰ Menu > Importer.
- Pour mettre à jour l'application web : remplacez les fichiers dans web/, puis régénérez SHA256SUMS.txt :
  cd web && sha256sum $(ls | sort) > ../SHA256SUMS.txt
